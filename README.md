Этот репозиторий создан для изучения системы контроля версий **Git** и сервиса **GitHub**.

---

## Цель работы

В ходе выполнения лабораторной работы вы научитесь:

- клонировать репозиторий;
- создавать ветки;
- создавать и изменять файлы;
- выполнять коммиты;
- отправлять изменения на GitHub;
- создавать Pull Request
